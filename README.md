# Book Search

There's a design doc at this level (`Design.md`), and everything else is in either `book-search-fastapi` or `book-search-ui`.

1. To run, the UI first needs to be built, which should work with a simple `npm install` followed by `npm run build` as discussed in `book-search-ui/README.md`.
2. Following that, follow the directions in `book-search-fastapi/README.md` to actually run the code.
